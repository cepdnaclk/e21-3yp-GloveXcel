# GloveXcel project page

This directory contains the public GitHub Pages showcase for **GloveXcel**, a smart wearable hand-rehabilitation system.

The published page presents the complete project story and feature set, including:

- wearable five-finger motion sensing and ESP32 processing;
- patient and doctor calibration;
- live and preloaded rehabilitation exercises;
- 3D movement visualisation and five-finger visual limit guidance;
- automatic repetition, set, peak-angle, and session tracking;
- configurable therapeutic resistance;
- therapist monitoring and role-based patient management;
- progress analytics and rehabilitation history;
- hardware, system architecture, testing, use cases, and project team.

Open [`index.html`](./index.html) to view the page source. GitHub Pages serves this file as the site homepage.
